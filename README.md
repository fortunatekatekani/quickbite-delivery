# QuickBite Delivery

Build me a web app called "QuickBite" - an Uber Eats style food delivery platform.

It must have 4 user types: Customer, Restaurant, Driver, and Admin.

Start with the Customer side first:

- Homepage with search bar and food categories

- List of restaurants with images, ratings, and delivery time

- Restaurant page with menu, prices, and "Add to Cart" button

- Shopping cart and checkout page

- Order tracking page with order status: Preparing, On the way, Delivered

Use a modern, clean, mobile-first design. 

Green and white color theme.

Use placeholder images and fake data for now.

Make it a clickable prototype.
